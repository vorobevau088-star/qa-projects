**Инструменты:** YouGile, Excel  
**Результат:** 15+ баг-репортов, тест-кейсы, чек-листы, отчёт о тестировании

**Виды тестирования:** smoke, функциональное, регресс, UI/UX, API (Charles)  
**Инструменты:** Excel, YouGile, Charles Proxy  
**Результат:** полный цикл тестирования с документированием

### 3. [Intershop — веб-сайт](./03-intershop/)
**Тип:** интернет-магазин (WooCommerce)  
**Виды тестирования:** функциональное, регресс, UI/UX, API (Postman), безопасность  
**Инструменты:** Postman, DevTools, Excel
